# OpenSimAvionics

Open-source 1:1 flight simulator avionics panels that are meant to be drop-in replacements for popular off-the-shelf panels.

## Technology Used

- Panel (shell) design: OpenCAD
- Microcontroller: Raspberry Pi Pico 2
- Microcontroller programming: C99
- Companion app programming: C++ and Raylib/Raygui
